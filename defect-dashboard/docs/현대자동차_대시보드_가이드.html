Stack & Setup
기술 스택 및 환경 구성
Python Transform 서버 (FastAPI + uvicorn)
# 1. 패키지 설치 pip install fastapi uvicorn pandas serpent requests # 2. 서버 기동 (Panopticon과 함께 start.bat에 자동화) cd "...\Panopticon_2609\python_integration\panopticon_fastapi_py" uvicorn app.main:app --host 0.0.0.0 --port 9090 # 3. 동작 확인 # http://localhost:9090/ → {"Hello":"World"}

Panopticon.properties — connector.python.host=localhost / connector.python.port=9090 / mode=fast_api

주요 해결 과제
java.net.ConnectException: Failed to connect to localhost:9090
Panopticon.properties는 올바르게 설정되어 있었으나 Python 실행 서버가 미기동 상태. uvicorn 프로세스를 별도 기동하고 start.bat에 자동화하여 해결.
No module named 'requests'
uvicorn이 실행 중인 Python 환경에 requests 미설치. pip install requests 후 재기동.
최적화 결과 미출력 (200 OK에도 불구)
P_target 하드코딩 + API 응답 파싱 코드 주석 처리 상태. result["data"]로 파싱, table = pd.DataFrame(...)으로 반환하도록 수정.
EXZ 가져오기 무음 실패 (X 표시)
ZIP 내 디렉터리 엔트리 누락 + thumbnail.png 미포함. 모든 디렉터리 엔트리 명시 + 1×1 투명 PNG 삽입으로 해결.
