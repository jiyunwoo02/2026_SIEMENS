모델 개요

Gradient Boosted Trees(GBT) 회귀 모델을 사용해 현재 공정 상태로부터 결함률(%)을 실시간 예측합니다. AI Studio에서 학습하고 AI Hub를 통해 REST API로 서빙됩니다.

공정 변수 12개 입력
→
AI Hub (deploy.rmp)
→
GBT 회귀 모델
→
defect_rate_pct (%)

변수명타입설명범위
production_linestring생산 라인LINE-BPR-01, LINE-BPR-02

등급 판정

양호 (Good)

불량 (Poor)

등급 판정은 Panopticon Python Transform 및 defect-predictor LLM 해설 단계에서 적용됩니다.
