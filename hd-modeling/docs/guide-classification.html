strore-classification-gbt-v0.3 defect-advisor

모델 개요

Gradient Boosted Trees(GBT) 분류 모델을 사용해 현재 공정 상태가 고결함 위험 조건(1)인지 정상 조건(0)인지 예측합니다. 분류 결과는 최적화 프로세스의 기반으로도 활용됩니다.
