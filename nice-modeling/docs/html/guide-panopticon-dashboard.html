만든 과정

3-1. 초안 분석

처음 대시보드는 AI Hub Endpoint 커넥터(AIHub)로 연결한 데이터 테이블 1개와 텍스트 박스 몇 개뿐이었으며, 두 가지 한계가 있었습니다.

  • 요청 본문(RequestBody)이 고정 샘플 1건이라 항상 같은 결과만 보임
  • 입력을 바꿀 위젯이 없음

3-2. 레퍼런스 분석

HT 목상해 예측 플랫폼 레퍼런스 워크북을 분석해 다음 패턴을 확인했습니다.

항목레퍼런스 방식
입력 위젯NumericActionSlider (수치) · ActionDropDown (범주)
위젯-파라미터 연결DashboardParameterName에 파라미터 이름 지정, ActionPartTriggerMode = Parameter
파라미터 정의대시보드와 데이터 테이블 양쪽에 같은 이름의 parameter 선언 (이름·기본값·타입)
모델 호출TEXT 데이터 소스 + Python Transform — 스크립트 안의 {P_변수명}이 파라미터 값으로 치환
결과 표시데이터 모드 텍스트 박스가 데이터 테이블 컬럼 표시
범주형 선택지값 목록을 가진 별도 TEXT 데이터 테이블을 드롭다운 소스로 사용

3-6. .exz 파일 구조

.exz는 ZIP 형식입니다. 주요 구성은 다음과 같습니다.

경로역할
Workbooks/<폴더>/<워크북>/workbook.json워크북 전역 설정
.../datatables/<id>.json데이터 테이블 정의 (소스·변환·스키마·파라미터)
.../dashboards/Dashboard1.json위젯 목록, 파라미터, 런타임 설정
.../datatables.list, dashboards.list포함된 데이터 테이블·대시보드 목록
.../mangling.txt한글 이름과 파일 경로 매핑
DataLibrary/datatables공유 데이터 테이블 저장소 (이번 버전은 비어 있음)

지원 기능

기능설명
실시간 입력 조절 슬라이더 47개로 신용 변수를 0~10 범위에서 직접 조절. 슬라이더를 움직이는 즉시 모델이 재호출됩니다.
신용점수 확인 Score — 0 ~ 1000점 (높을수록 우량)
불량·정상 확률 confidence(1) (불량확률) · confidence(0) (정상확률) 동시 표시
target 예측 prediction(TARGET) — 0 (정상) 또는 1 (불량)
판정 문구 Result — target 값에 따라 정상 / 불량 표시
신용등급 구간 Grade — 점수 구간을 6단계로 분류
점수 구간 띠 0~1000 척도와 구간별 색을 참조용으로 함께 표시
재현 가능한 배포 워크북을 .exz로 내보내 버전으로 관리하고 다른 환경에서 가져올 수 있습니다.

사용 방법

  1. 파일 가져오기
    Panopticon Designer에서 261109_dashboard_v3_sliders.exz를 가져옵니다.
  2. Python 환경 확인
    Panopticon의 Python 서버가 실행 중이고 pandas·requests 패키지가 설치되어 있는지 확인합니다.
  3. 대시보드 열기
    261109_Workbook → Dashboard1을 엽니다.
  4. 슬라이더 조작
    좌측 슬라이더 47개로 신용 변수 값을 0~10 범위에서 조절합니다.
  5. 결과 확인
    우측 패널의 신용점수·불량확률·정상확률·target 예측·판정·신용등급 구간이 갱신되는지 확인합니다.

문제 해결 기록

#증상원인해결상태
1 판정·등급 박스에서 Aggregate binding failed: column ... has bad type 텍스트 컬럼 박스의 가중치 컬럼(WeightColumnName)을 텍스트 컬럼 자신으로 지정 — 가중치는 숫자형이어야 함 텍스트 컬럼 박스의 가중치 컬럼을 숫자 컬럼(Score)으로 변경 ✅ 해결

운영 중 값이 나오지 않을 때 확인 항목

  • Python 서버 기동 여부, requests 설치 여부
  • 엔드포인트 인증 필요 여부 (현재 스크립트는 인증 헤더 없이 호출)
  • 슬라이더 이름 / 파라미터 이름(P_ + 컬럼명) / 스크립트의 {P_...} 자리 표시자가 모두 일치하는지
AI Hub 스코어링 모델 자체 트러블슈팅 이력은 docs/guide-nice-scoring.html의 트러블슈팅 섹션을 참조하세요.
