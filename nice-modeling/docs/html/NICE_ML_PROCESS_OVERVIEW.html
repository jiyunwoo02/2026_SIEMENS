3.3 신용점수 산출 원리

confidence(0)과 confidence(1)은 항상 합이 1이다. 두 값의 비율(오즈, odds)을 로그 변환하여 선형 점수로 변환한다.

odds  = confidence(0) / confidence(1)   # 정상/불량 확률 비율
Score = 640 + (80/ln2) × ln(odds)
      = 640 + 115.42 × ln(odds)
상황oddsln(odds)Score (대략)
정상 확률 압도적으로 높음≫ 1양수 (큰 값)640 초과, 최대 1,000
정상·불량 확률 동일= 10640 (기준점)
불량 확률이 더 높음< 1음수640 미만, 최소 0
  • 점수가 높을수록 신용 우량 (정상 가능성 ↑)
  • 기준점 640은 odds = 1 (정상·불량 확률 50:50)일 때의 점수

4.2 신용점수 산출 공식

원본 Python 공식

def rm_main(data):
    anchor = 640
    pdo    = 80
    factor = pdo / np.log(2)   # 80 / ln(2) ≈ 115.41560327
    offset = anchor             # 640

    p_pos = data['confidence(1)'].values + 1e-10   # 불량(1) 확률
    p_neg = data['confidence(0)'].values + 1e-10   # 정상(0) 확률

    odds = p_neg / p_pos   # confidence(0) / confidence(1)

    data['Score'] = offset + (factor * np.log(odds))
    data['Score'] = data['Score'].clip(lower=0, upper=1000).round(0).astype(int)
    return data

import requests

url = "https://mlops.nice.plda-cloud.com/webapi/DEFAULT/api/v1/services/nice-scoring/deploy_scoring_process_v02"
headers = {"Content-Type": "application/json"}

payload = {
    "data": [{
        "KEY": 1,
        "R1_CBINQ_CNT05": 2.0,
        # ... (나머지 47개 컬럼)

result = response.json()
