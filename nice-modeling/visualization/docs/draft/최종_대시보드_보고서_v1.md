## 1. 개요

NICE 신용평가 데이터 기반 LightGBM 분류 모델의 예측 결과를 Panopticon Designer에서 실시간으로 탐색할 수 있는 대시보드를 구축하였습니다.  
사용자가 신용 변수 47개를 슬라이더로 직접 조절하면 AI Hub 스코어링 엔드포인트가 다시 호출되어 신용점수, 불량·정상 확률, target 예측, 등급이 즉시 갱신됩니다.  
최종 버전(`261111_UI수정_게이지.exz`)에서는 UI를 개선하고 **반원형 게이지(Radial Gauge)** 를 추가하여 현재 점수 위치를 직관적으로 파악할 수 있도록 하였습니다.

## 2. 개발 과정 요약

### 2-1. 초안 분석

초기 대시보드는 AI Hub Endpoint 커넥터로 연결한 데이터 테이블과 텍스트 박스 몇 개로만 구성되어 있었습니다.  
요청 본문이 고정 샘플 1건이라 항상 같은 결과만 출력되고, 입력을 바꿀 위젯이 전혀 없는 한계가 있었습니다.

### 2-2. 레퍼런스 패턴 적용

HT 목상해 예측 플랫폼 워크북을 레퍼런스로 분석하여 다음 패턴을 채택하였습니다.

| 요소 | 적용 방식 |
| --- | --- |
| 입력 위젯 | `NumericActionSlider` 47개 (변수별 슬라이더) |
| 파라미터 연결 | 위젯의 `DashboardParameterName`에 `P_` + 컬럼명 지정 |
| 데이터 소스 | TEXT 소스 + Python Transform (REST 호출) |
| 파라미터 치환 | Python 스크립트 내 `{P_변수명}` 자리 표시자로 슬라이더 값 전달 |
| 결과 표시 | 데이터 모드 텍스트 박스 + 반원형 게이지 |

## 3. 시스템 구조

```
[슬라이더 47개]                    [DataTable1]                        [AI Hub]
 NumericActionSlider1  ─┐           TEXT 소스 (헤더 + {P_변수명} 행)
 NumericActionSlider2  ─┼─ 파라미터 ─→ Python Transform
 ...                   ─┘             · JSON 본문 조립 ({P_변수명} → 슬라이더 값)
 NumericActionSlider47 ─┘             · POST ──────────────────────────→  nice-scoring v02
                                      · 응답(prediction, confidence, Score) ←── (Set Role
                                      · Result, Grade 컬럼 추가                   → Apply Model
                                            │                                      → Generate Attributes)
                                            ▼
                           [결과 패널]
                           ┌─────────────────────────────────┐
                           │  신용점수 (Score)  │  등급 (Grade)  │
                           │                               │
                           │  ◉ 반원형 게이지 (0–1000)      │
                           │    Red → Yellow → Green       │
                           │                               │
                           │  불량확률 │ 정상확률 │ target  │
                           │  판정(Result)                  │
                           └─────────────────────────────────┘
```

슬라이더가 만드는 **대시보드 파라미터**를 데이터 테이블이 `{P_변수명}` 자리 표시자로 받아 쓰는 것이 핵심 메커니즘입니다.  
파라미터가 변경되면 데이터 테이블이 재실행되고, 데이터 테이블을 참조하는 모든 위젯이 함께 갱신됩니다.

## 4. 구성 요소 상세

### 4-1. 데이터 테이블 (DataTable1)

| 항목 | 내용 |
| --- | --- |
| 데이터 소스 | TEXT 플러그인 (헤더 1행 + 데이터 1행) |
| 컬럼 수 | 입력 48개 (`KEY` + 변수 47개) + 출력 6개 = **54개** |
| 출력 컬럼 | `prediction(TARGET)`, `confidence(0)`, `confidence(1)`, `Score`, `Result`, `Grade` |
| Transform | Python Transform (`pandas`, `requests`) |
| 파라미터 수 | 47개 (NUMERIC, `P_` + 컬럼명) |
| 캐싱 | 활성화 (`isCachingEnabled: true`) |

**TEXT 소스 구조** (2행):
```
KEY, R1_CBINQ_CNT05, R1_CBINQ_CNT10_CD, ... (헤더)
1, {P_R1_CBINQ_CNT05}, {P_R1_CBINQ_CNT10_CD}, ...  (슬라이더 값 자리)
```

**Python Transform 처리 흐름**:

```python
# 1. {P_변수명}이 치환된 JSON 본문 조립
json_data = {
    "data": [{
        "KEY": 1,
        "R1_CBINQ_CNT05": {P_R1_CBINQ_CNT05},
        # ... 나머지 46개 변수
    }]
}

# 2. AI Hub 엔드포인트 POST 호출
endpoint_url = "https://mlops.nice.plda-cloud.com/webapi/DEFAULT/api/v1/services/\
nice-scoring/deploy_scoring_process_v02"
result = requests.post(endpoint_url, json=json_data, headers={'Content-Type': 'application/json'})

# 3. 응답을 DataFrame으로 변환
df = pd.DataFrame(result.json()['data'])

# 4. 파생 컬럼 추가
df['Score'] = pd.to_numeric(df['Score'], errors='coerce')
df['Result'] = df['prediction(TARGET)'].apply(lambda v: "불량" if float(v) == 1 else "정상")
df['Grade']  = df['Score'].apply(score_grade)  # 등급 함수 (아래 §6 참조)

table = df
```

## 6. 신용등급 분류 기준

Python Transform 내 `score_grade` 함수 기준:

```python
def score_grade(score):
    if score >= 900: return "최우수"
    elif score >= 800: return "우수"
    elif score >= 700: return "양호"
    elif score >= 600: return "보통"
    elif score >= 500: return "주의"
    return "위험"
```

| 점수 구간 | 등급 | 게이지 색 |
| --- | --- | --- |
| 900 이상 | 최우수 | 초록 (진) |
| 800 ~ 899 | 우수 | 초록 |
| 700 ~ 799 | 양호 | 연두 |
| 600 ~ 699 | 보통 | 노랑 |
| 500 ~ 599 | 주의 | 주황 |
| 500 미만 | 위험 | 빨강 |

## 9. 사용 방법

1. Panopticon Designer에서 `261111_UI수정_게이지.exz`를 가져옵니다.
2. Panopticon의 Python 서버가 기동 중이고 `pandas`, `requests`가 설치되어 있는지 확인합니다.
3. 대시보드를 열고 슬라이더를 조작합니다.
4. 우측 패널의 신용점수·등급·게이지·확률·판정이 갱신되는지 확인합니다.
