📋개요

NICE 신용평가 데이터 기반 LightGBM 분류 모델의 예측 결과를 Panopticon Designer에서 실시간으로 탐색할 수 있는 대시보드를 구축하였습니다. 사용자가 신용 변수 47개를 슬라이더로 조절하면 AI Hub 스코어링 엔드포인트가 다시 호출되어 신용점수·불량 확률·등급이 즉시 갱신됩니다. 최종 버전에서는 UI를 개선하고 반원형 게이지(Radial Gauge)를 추가하여 현재 점수 위치를 직관적으로 파악할 수 있도록 하였습니다.

🎯신용등급 분류 기준

def score_grade(score):
    if score >= 900: return "최우수"
    elif score >= 800: return "우수"
    elif score >= 700: return "양호"
    elif score >= 600: return "보통"
    elif score >= 500: return "주의"
    return "위험"
⚠️ 위 등급 기준은 현재 예시 기준입니다. 운영 기준 확정 후 Python Transform 스크립트와 게이지 색상 범위에 반영해야 합니다.
