# Siemens AI Demo

Siemens AI Platform 관련 서비스 연동 및 로컬 머신러닝 데모 프로젝트입니다.

## 프로젝트 구성

### 1. AIHUB
자연어 질의를 외부 예측 API와 연결하는 서비스입니다.

- 자연어 기반 질의 처리
- 외부 예측 API 연동
- API 응답을 활용한 예측 결과 제공

### 2. ICX_DEMO
로컬 환경에서 머신러닝 모델의 학습 및 예측 과정을 확인하기 위한 데모입니다.

- 데이터 기반 모델 학습
- 학습된 모델을 활용한 예측
- 로컬 환경에서의 머신러닝 워크플로 검증

## 실행 전 확인 사항

- `ICX_DEMO/requirements.txt`에 필요한 Python 패키지를 명시해야 합니다.
- 학습 코드에서 참조하는 CSV 파일 경로와 실제 데이터 파일명이 일치하는지 확인해야 합니다.
- `AIHUB`와 `ICX_DEMO`는 각각 별도의 목적을 가진 프로젝트로, 현재 자동으로 연동되지 않습니다.
- 외부 API를 사용하는 경우 API 주소, 인증 정보 및 요청 형식을 확인해야 합니다.

## 개발 환경

- Python
- AIHUB: 외부 예측 API 연동
- ICX_DEMO: 로컬 머신러닝 모델 학습 및 예측
